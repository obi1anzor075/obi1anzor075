<h2>About me</h2>

<p>I’m Daniil, a C# / .NET backend developer. I build web APIs, background services, and integrations, with a focus on clear application boundaries, data access, authentication, and deployment.</p>

<table>
  <thead><tr><th>Approach</th><th>How I use it</th></tr></thead>
  <tbody>
    <tr><td><strong>Clean / layered architecture</strong></td><td>Separate domain logic, application use cases, infrastructure, and presentation.</td></tr>
    <tr><td><strong>CQRS &amp; Mediator</strong></td><td>Separate command and query handlers with MediatR.</td></tr>
    <tr><td><strong>Repository &amp; DI</strong></td><td>Access data through interfaces and inject dependencies.</td></tr>
    <tr><td><strong>Result pattern</strong></td><td>Express success and failure outcomes explicitly.</td></tr>
    <tr><td><strong>DDD concepts</strong></td><td>Use Value Objects and Domain Events in domain models.</td></tr>
    <tr><td><strong>Pipeline behaviors</strong></td><td>Apply validation, authorization, logging, and performance monitoring around handlers.</td></tr>
    <tr><td><strong>Factory &amp; Adapter</strong></td><td>Create domain-specific objects and adapt external API clients to application interfaces.</td></tr>
  </tbody>
</table>
